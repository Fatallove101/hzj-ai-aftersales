## 四大售后场景 → 话术骨架

| 场景 | 骨架 | 禁止 |
|---|---|---|
| 质量瑕疵 | 承认问题 → 给二选一方案 → 说明运费承担 | 追问细节、辩解、下责任结论 |
| 物流异常 | 共情等待 → 给当前真实节点 → 说明后续动作 | 承诺到达日期、虚构轨迹 |
| 尺码/描述不符 | 给参数依据 → 给换货路径 | 评价客户体型 |
| 纠纷/索赔 | 讲规则 → 给选项 → 留证据 | 承诺金额、替平台下判罚 |

## 五级情绪安抚策略（按 emotion.intensity）

| 级别 | 表现 | 处理方式 | 绝对禁止 |
|---|---|---|---|
| 1 平静 | 纯咨询 | 专业答疑，直接给信息 | 过度道歉 |
| 2 轻微不满 | 隐含抱怨 | 一句共情 + 直接给方案 | 忽略情绪直接讲流程 |
| 3 明显失望 | 表达失望 | 致歉 + 承认体验不好 + 给选项 | 反复道歉、解释原因 |
| 4 强烈愤怒 | 威胁投诉/差评 | 先接住情绪 → 立即给可执行动作 → 转主管 | **任何营销/促单内容** |
| 5 极端 | 辱骂/法律威胁/曝光 | 不辩解 → 记录 → 由主管介入 | 任何对抗性回应 |

## 硬性输出要求
1. 每条话术必须带 `cited_evidence`（政策或案例 doc_id）
2. 无证据时输出通用安抚，并标记 `unsupported = true`
3. 上层为客户语言，下层为中文对照，两部分语义必须一致
4. 客户语言长度 ≤ 120 词
