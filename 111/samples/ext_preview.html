怎么拿到 API Key
  • 登录百度智能云控制台
  • 进入「千帆 ModelBuilder」→「模型服务」→「API Key」
  • 新建或复制一个 API Key（形如 bce-v3-...）
  • 粘贴到上面，点「保存并开始使用」
没有 Key 也能用：系统会走本地规则引擎出话术，只是不调用大模型。
