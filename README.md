# 汉正街跨境售后 AI 话术助手

面向武汉汉正街服装跨境商户的多语言售后话术助手，基于百度千帆构建。
本仓库包含**设计方案**与**可运行的本地演示**两部分。

## 快速运行演示

双击 `111\启动.bat`，浏览器会自动打开 <http://127.0.0.1:8799/>

零依赖：不需要 Python、Node，也不需要管理员权限。只用系统自带的 PowerShell 5.1 + Windows 内置 OCR。

---

## 演示能做到什么

- **自动读取对话**：自动读屏（OCR）/ 剪贴板监听 / UI Automation 直接取文本 / 手动粘贴，四种方式
- **理解客户**：14 类意图识别、情绪强度、紧急度分级、风险标记
- **检索知识**：18 条各国政策 + 46 条服装跨境术语，按国家/平台/生效日期过滤
- **生成话术**：≤3 条候选，五种风格（安抚致歉 / 专业答疑 / 营销促单 / 纠纷调解 / 合规告知）
- **合规闸门**：真实执行 25 条规则的正则校验，`reject` 的话术永不进入最终输出
- **转人工判定**：命中平台介入 / 拒付 / 法律风险 / 知识无依据等条件时强制转人工
- **数据闭环**：采纳 / 修改 / 忽略写回日志，统计采纳率

## 自检

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 111\tools\selfcheck.ps1
```

三部分：模板合规自检（126 条话术 × 25 条规则）、7 个行为用例回归、26 条合规闸门单元测试。

---

## ⚠️ 两条务必注意

1. **编辑 `.ps1` 后必须存成 UTF-8 带 BOM**，否则 PowerShell 5.1 按 ANSI 解析，中文乱码会破坏引号配对导致语法错误。详见 `111/README.md` 第十节。
2. **`agent设计/data/compliance_rules.csv` 与 `policy_index.csv` 是种子数据，不是法律意见**。法条编号、期限、运费承担口径上线前必须由法务逐条核实（`status` 由 `seed` 改为 `active`）。
