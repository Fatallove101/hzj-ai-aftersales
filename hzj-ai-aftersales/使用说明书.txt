======================================================================
                跨境销售 AI 话术助手 · 使用说明书
======================================================================

  版本：v0.43.1
  适用：Windows 10 / 11 + Edge 或 Chrome 浏览器
  零依赖：不需要 Python、Node，不需要管理员权限

  【先看这一句】
  这个工具分两部分：
    1) 本地服务（真正干活的大脑）—— 必须启动
    2) 浏览器扩展（你看到的界面）—— 连上服务才能用

  所以顺序永远是：**先启动服务，再用扩展**。
  想省掉这步，见「六、开机自启」。


----------------------------------------------------------------------
一、这个工具是什么
----------------------------------------------------------------------

  给跨境销售客服坐席用的 AI 话术副驾。

  它做四件事：
    读懂客户 → 查准依据 → 生成话术 → 一键插入

  覆盖售前（尺码/材质/运费咨询）、售中（催发货/改地址）、
  售后（退换货/色差/物流丢件/差评沟通）全链路。

  ⚠️ 重要：它不是「AI 客服」，也永远不会直接给客户发消息。
     它只给人工坐席提供话术建议，由人确认后再发出去。


----------------------------------------------------------------------
二、第一次使用：照这个顺序做
----------------------------------------------------------------------

  第 1 步  启动本地服务
           双击  hzj-ai-aftersales\启动演示页面.bat
           （会弹出一个黑色窗口，显示服务启动信息）

  第 2 步  确认服务起来了
           窗口里出现这一行就是成功：
             服务已启动 →  http://127.0.0.1:8799/mock.html

  第 3 步  导入浏览器扩展（见「三」）

  第 4 步  填你自己的千帆 API Key（见「五」）
           ★ 第一次使用必须填，否则只能用本地规则模板

  第 5 步  在客服页面上校准一次选择器（见「七」）

  之后每天用：启动服务 → 打开客服后台 → 点扩展 → 用


----------------------------------------------------------------------
三、导入浏览器扩展
----------------------------------------------------------------------

  以 Edge 为例（Chrome 完全一样，把 edge:// 换成 chrome://）：

  1) 地址栏输入：edge://extensions/
     回车

  2) 打开左下角的「开发人员模式」开关

  3) 点上方出现的「加载解压缩的扩展」按钮

  4) 在弹出的文件夹选择框里，选中这个目录：
         hzj-ai-aftersales\extension
     （注意：选 extension 这一层，不要选它的上级）

  5) 看到「跨境销售 AI 话术助手」出现在列表里就成功了

  6) 打开你的客服后台页面（或演示页），
     点浏览器右上角的扩展图标 → 侧边栏就出来了

  ---------------------------------------------------------------
  关于扩展图标：
    如果工具栏上没看到图标，点一下地址栏右边的「拼图」图标，
    在里面找到它，点右边的图钉把它固定住。
  ---------------------------------------------------------------

四、启动本地服务（.bat 文件说明）
----------------------------------------------------------------------

  项目里有三个可以双击的东西，用途不同：

  ------------------------------------------------------------------
  【1】启动演示页面.bat
       启动服务 + 自动打开「模拟客服页」
       这是给测试扩展用的假客服后台，不是产品本体。
       地址：http://127.0.0.1:8799/mock.html

       ★ 推荐用这个做第一次体验 —— 页面里自带 5 个演示剧本
         （德语色差 / 西语尺码 / 英语物流 / 日语瑕疵 / 中文退款）

  ------------------------------------------------------------------
  【2】启动网页（推荐用扩展，详见README）.bat
       启动服务 + 自动打开「坐席工作台」网页版
       地址：http://127.0.0.1:8799/

       网页版功能比扩展少一点（不能自动读别的网页上的对话），
       但不需要装扩展，适合先看看效果。

  ------------------------------------------------------------------
  【3】tools\autostart.ps1
       不是双击的，是「装开机自启」的脚本，见「六」。
  ------------------------------------------------------------------

  ⚠️ 那个黑色窗口：
     · 它是服务本体，**不能关**。关了服务就停了，扩展立刻用不了。
     · 最小化可以，关掉不行。
     · 想停服务：在那个窗口里按 Ctrl+C，或直接关窗口。

五、连接千帆 API Key（第一次必看）
----------------------------------------------------------------------

  ★★★ 第一次使用，你需要填自己的 API Key ★★★
      本项目**不提供** API Key。每个人用自己的百度千帆账号。
      没有 Key 也能用，但只能用「本地规则模板」，
      话术是固定模板，翻译也只有术语级对照，不是模型生成的。

  ---------------------------------------------------------------
  【怎么拿到 API Key】
    1) 登录 百度智能云  https://console.bce.baidu.com/
    2) 进入「千帆 ModelBuilder」
    3) 找到「模型服务」→「API Key」
    4) 新建或复制一个，形如： bce-v3/ALTAK-xxxxxxxx/xxxxxxxx
  ---------------------------------------------------------------

  ---------------------------------------------------------------
  【怎么填进去 —— 两种方式，任选一种】

  方式 A：在扩展里填（推荐）
    1) 点扩展面板页脚的「🔑」按钮
    2) 如果还没配过 Key，扩展会自动跳到这个页面
    3) 把 Key 粘贴进「百度千帆 API Key」输入框
    4) 模型名建议填： ernie-4.5-turbo-128k
       接口地址建议填： https://qianfan.baidubce.com/v2
    5) 点「保存并开始使用」

  方式 B：在网页版里填
    1) 打开 http://127.0.0.1:8799/
    2) 左侧菜单点「设置」
    3) 找到「API Key」那一块，粘贴 → 点「保存」
  ---------------------------------------------------------------

  ---------------------------------------------------------------
  【Key 是怎么存的 —— 安全性说明】
    · 用 Windows DPAPI 加密后存在本机：
        %APPDATA%\hzj-agent\credential.dat
    · 明文不落盘、不进日志、不进 git
    · 接口永远不会把 Key 回显出来（只返回一个 8 位指纹，
      用来让你确认「存的是不是这一把」）
    · 换电脑要重新填（DPAPI 加密跟「Windows 账号 + 这台机器」绑定，
      复制 credential.dat 到别的电脑解不开）
  ---------------------------------------------------------------

  ---------------------------------------------------------------
  【关于账号欠费】
    如果报 account_overdue，说明你的百度云账号欠费或该模型未开通。
    实测可用的模型是： ernie-4.5-turbo-128k
    （ernie-4.0-8k-latest 报 account_overdue，用不了）
  ---------------------------------------------------------------


----------------------------------------------------------------------
六、开机自启（不想每次都手动启动服务）
----------------------------------------------------------------------

  浏览器扩展在技术上**没法启动本机程序** —— 这是浏览器的安全限制，
  没有对应 API。所以服务必须有人拉起来。

  装一次自启，以后开机就自动在后台跑，不用再管：

    打开 PowerShell（或在本文件夹按住 Shift 右键 → 在此处打开 PowerShell）

    powershell -ExecutionPolicy Bypass -File tools\autostart.ps1 -Install

  装完之后：登录 Windows 时服务静默启动（不弹窗口、不占任务栏），
  打开任何网页 + 点扩展都能直接连上。

  ---------------------------------------------------------------
  【看状态 / 卸载】
    看状态：powershell -ExecutionPolicy Bypass -File tools\autostart.ps1
    卸 载：powershell -ExecutionPolicy Bypass -File tools\autostart.ps1 -Uninstall
  ---------------------------------------------------------------

七、连接知识库
----------------------------------------------------------------------

  【默认状态：本地知识库，开箱即用】
    项目自带一套 CSV 知识库，不用配任何东西就能用：
       · 各国消费者保护政策   20 条
       · 服装跨境术语         46 条
       · 合规规则             30 条
       · 意图标签             14 类

  【想换成千帆知识库】
    1) 打开扩展 → 页脚「⚙」设置 → 找到「知识源」
    2) 把「本地 CSV 知识库」改成「千帆知识库（MCP / AppBuilder）」
    3) 填写：
         千帆检索端点    ← 必填。从千帆控制台拿到的检索地址
         AppBuilder 应用 ID  ← 选填
         知识库 / 数据集 ID  ← 选填
    4) 点「保存」
    5) 点「测试连接」看通不通

  ⚠️ 诚实说明：
     千帆知识库这条路**还没有对接过真实接口**。
     契约已经定义好了（要什么字段、返回什么格式），详见
       docs\接入千帆知识库.md
     如果千帆返回的字段名和我们约定的不一样，需要改
       engine\knowledge.ps1  里的字段映射。
     在对接成功之前，它会自动降级到本地 CSV，并在界面上写明降级原因。

  【想改本地知识库的内容】
    直接编辑 data\ 目录下的 CSV 文件，存盘后重启服务即可：
       policy_index.csv              政策库
       glossary_zh_en_es_de_fr.csv   术语库
       compliance_rules.csv          合规规则
       intent_taxonomy.csv           意图标签

  【想加自己的禁用表述】
    扩展 → ⚙ 设置 → 「自定义禁用表述」→ 填规则名 + 关键词/正则 → 添加
    服务端会拿合规正向样本试跑一遍，如果会误杀正常话术会警告你。

八、日常使用
----------------------------------------------------------------------

  【读取对话的五种方式】
    页面    —— 直读网页 DOM，最准，首选（普通网页都能用）
    剪贴板  —— 在任何软件里选中文字 Ctrl+C，再点它
    窗口    —— 直读某个桌面窗口的文字（不走 OCR，无识别误差）
    读屏    —— 截图 + Windows OCR（页面读不到时用，有识别误差）
    手动    —— 自己粘贴或输入（任何来源都能用）

  【三框工作台】
    ① 客户对话   —— 读到什么、翻译成什么
    ② 候选话术   —— 生成的候选，点「换一批」重新生成
    ③ 详情       —— 读取设置、当前平台、意图情绪、政策依据

  【第一次在某个平台上用，要校准一次】
    1) 点扩展页脚的「⌖」按钮
    2) 点「① 拾取「消息区」容器」→ 然后在页面上点一下对话列表区域
    3) 点「② 拾取「回复输入框」」→ 再点一下输入框
    4) 选择器只存在本机浏览器里，以后不用再拾

    ★ 拾取过的选择器**优先级高于自动识别**。
      接新平台（TikTok / Amazon 之外）时，这是最靠谱的一步。

  【生成话术要等 20~40 秒】
    因为要调两次大模型（先翻译、再生成）。
    界面上会显示「已等待 N 秒」，这是正常的，不是卡死。

  【修改后采纳】
    对候选话术不满意，可以点「✎ 修改后采纳」：
      · 改上面的中文 → 下面的外文会自动重新翻译（保证内外一致）
      · 确认后点「⤵ 插入输入框」直接写进回复框

九、使用注意（重要）
----------------------------------------------------------------------

  1. 服务窗口不能关
     关了扩展立刻显示「连不上本地服务」。

  2. 合规规则库是「待法务确认」的种子数据
     data\compliance_rules.csv 和 policy_index.csv 是**工程数据，
     不是法律意见**。上线前必须经法务逐条核对。

  3. 工具不会自动发送任何消息
     所有话术都要你人工确认后自己发。
     界面上没有「自动回复」这种功能，是故意的。

  4. 标记为「不可发送」的话术不会出现在候选里
     合规闸门在服务端执行，被拦的话术前端根本收不到。

  5. 高风险案件会明确标出来
     命中平台介入 / 拒付 / 法律风险 / 知识无依据时，
     会显示「⚠ 高风险案件 · 回复前请核实」，提醒你先核实再回。

  6. 换品类要换数据
     术语库以服装类目起家（色差/起球/缩水/做工）。
     换 3C、家居、美妆等品类时，按同样格式扩充
     data\glossary_zh_en_es_de_fr.csv 即可，代码不用改。

  7. 不要提交 config.local.json
     里面是你的个人配置。项目已经把它加进 .gitignore 了，
     你自己备份/拷贝时也注意别把它传到公开地方。

十、出问题了怎么办
----------------------------------------------------------------------

  【扩展显示「连不上本地服务」】
   原因：本地服务没启动，或者那个黑窗口被关了。
   解决：双击 启动演示页面.bat 重新启动服务。

  【点「换一批」显示「生成失败」】
   1) 先看黑窗口里有没有报错
   2) 再看扩展面板里「上次请求失败（服务连接正常）」那个橙色横幅，
      里面的文字会写明具体原因
   3) 常见原因：API Key 没填 / 账号欠费 / 网络不通

  【读不到对话，显示「还没生成话术」】
   1) 确认读取源选的是「页面」
   2) 点页脚「⌖」手动拾取一次「消息区」容器
   3) 或者换用「手动」读取源，自己把对话粘进去

  【没有中文整句翻译，只有术语对照】
   说明当前没接上模型（本地规则模式）。
   界面上会明确写「本地演示未接入翻译模型」——
   这是如实告知，不是 bug。填好 API Key 就有整句翻译了。

  【服务窗口报「端口 8799 上已经有一个本服务在运行」】
   说明已经有一个服务在跑了，**这是正常的**。
   那个新窗口可以直接关掉，后台那个服务不受影响。
   直接去用扩展就行。

  【想彻底重来】
   1) 关掉所有黑色服务窗口
   2) 删掉 config.local.json（会重置模型配置；API Key 不受影响）
   3) 重新双击 bat

十二、这个版本验证过什么
----------------------------------------------------------------------

  每次改动都会跑一套 10 项自动化自检，全部通过才提交：

    1) 编码检查       .ps1 必须带 BOM / .json 不能带 BOM / .bat 必须纯 ASCII
    2) 文档引用检查   文档里写的项目内路径是否真实存在
    3) 扩展加载检查   8 个脚本共同作用域加载 + 渲染冒烟 + 视图路由 + CSS class
    4) 扩展契约检查   扩展与后端的请求体形状
    5) 前端渲染测试   22 项单元测试
    6) JS 结构校验
    7) 后端自检       行为用例 + 合规闸门单元测试 + 日志脱敏（默认不调模型）
    8) 布局实测       无头浏览器真实测量
    9) 模拟页自检     用扩展真实提取代码跑模拟页，验证两条路径
   10) 语法检查       JS 真解析 + PowerShell 真解析

  想自己跑一遍：进 tools 目录，逐个执行（命令写在 README.md 里）。
